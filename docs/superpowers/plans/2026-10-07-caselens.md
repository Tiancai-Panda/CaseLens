# CaseLens Implementation Plan

> **For agentic workers:** Use inline execution of the approved design task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver an installable evidence-grounded VLM/Jev agent with an honest offline demonstration and real API adapters.

**Architecture:** Typed clients feed a bounded native-tool-calling loop. A per-run tool service owns asset/evidence/policy state; a SQLite store owns versioned cache and resumable batch checkpoints. CLI and evaluation consume the same results.

**Tech Stack:** Python 3.11+, Pydantic 2, httpx, Pillow, Typer, official typesafe-sdk, asyncio, SQLite, pytest.

**Spec:** `docs/design.md`

## Global Constraints

- Six controller rounds; two additional analyses per original image; default category probability threshold 0.80.
- API calls only; no model training, deployment or fine-tuning.
- Keys only from named environment variables. No refunds or other external business writes.
- Demo results carry mode=replay. No fabricated evaluation dataset or live validation claim.
- Independent operations only may run concurrently. New evidence invalidates stale decisions.
