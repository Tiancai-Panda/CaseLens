# return-request

Separate the requested return from condition findings. Ask for an order reference and return reason; do not relabel preference as damage. Read evidence and transform images when they clarify a stated condition. Merchant deadlines, eligibility and amounts remain unknown until supplied. Present the existing Policy-gated recommendation or human review; never create a real return or refund.
