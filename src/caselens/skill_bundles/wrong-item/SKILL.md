# wrong-item

Read the ordered SKU/model and received-item labels using evidence IDs. Compare brand, model, size, color and contents separately. Crop or rotate labels through available image tools and retain provenance. Request the ordered specification and readable label if missing. Distinguish uncertainty from confirmed mismatch. Policy and approval gates control actions.
